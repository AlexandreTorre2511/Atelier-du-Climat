# ✅ CHECKLIST AVANT PUBLICATION

À passer en revue soi-même, dans le navigateur, avant de mettre quoi que ce soit en ligne.
Ne jamais publier sur la foi d'un « c'est fait » : ouvrir, cliquer, vérifier.

## Contenu — la plus importante
- [ ] **Chaque chiffre du site est vrai et prouvable** (clients, années, note, avis)
- [ ] Aucun avis client inventé
- [ ] Aucune certification ou label que l'entreprise ne détient pas
- [ ] Aucun `{{À COMPLÉTER}}` ni `{{VARIABLE}}` restant — chercher `{{` dans tous les fichiers
- [ ] Aucun texte d'exemple (« Lorem ipsum », « Jean Dupont », « 06 00 00 00 00 »)
- [ ] Les prix sont identiques partout : accueil, pages offres, calculateur, navbar
- [ ] Le compte à rebours, s'il y en a un, a une vraie date de fin
- [ ] Les notifications de preuve sociale sont désactivées, ou contiennent de vrais clients
- [ ] Relecture orthographique de la page d'accueil et de la page contact

## Liens et navigation
- [ ] Cliquer sur **tous** les liens de la navbar et du footer : aucune erreur 404
- [ ] Les liens des réseaux sociaux pointent vers de vrais comptes (ou sont retirés)
- [ ] Le téléphone est cliquable et compose le bon numéro depuis un mobile
- [ ] Le bouton WhatsApp ouvre la bonne conversation
- [ ] L'email est cliquable et correct
- [ ] Le menu burger s'ouvre et se ferme sur mobile
- [ ] La recherche interne renvoie des résultats qui existent

## Formulaire — à tester en vrai
- [ ] Envoyer une demande de test complète
- [ ] L'email arrive bien (vérifier aussi les spams)
- [ ] Toutes les informations saisies sont présentes dans l'email
- [ ] Le bouton « Répondre » renvoie vers l'adresse du prospect
- [ ] Le message de succès s'affiche après l'envoi
- [ ] Les champs obligatoires bloquent bien un envoi incomplet

## Affichage
- [ ] Testé sur un vrai téléphone, pas seulement en mode réduit du navigateur
- [ ] Aucune barre de défilement horizontale, sur aucune page
- [ ] Toutes les images s'affichent (aucune icône cassée)
- [ ] Le texte reste lisible sur les fonds foncés et sur les fonds colorés
- [ ] Le logo s'affiche dans la navbar, le footer, et comme favicon dans l'onglet

## Technique
- [ ] Tester le JSON-LD sur search.google.com/test/rich-results : aucune erreur
- [ ] Aucune image au-dessus de 300 Ko
- [ ] `sitemap.xml` : toutes les pages, le bon domaine, aucune page inexistante
- [ ] `robots.txt` : le bon domaine dans l'URL du sitemap
- [ ] Toutes les URLs du site utilisent le domaine définitif, pas l'adresse `.netlify.app`

## Légal
- [ ] Mentions légales complètes, avec le vrai SIRET et la vraie adresse
- [ ] Politique de confidentialité en place, avec l'email de contact
- [ ] Les deux pages sont accessibles depuis le footer de **toutes** les pages
- [ ] Le bandeau cookies apparaît, et Analytics ne se charge qu'après acceptation
